# EARTH, SO FAR — storyboard

Visual system: black void, extreme-macro planet horizons with rim light (reference homage),
serif statements (Instrument Serif) + mono science labels (IBM Plex Mono), a persistent
deep-time counter. Every scene is a WebGL program in one engine canvas (`index.html`),
text/HUD/charts are DOM on top. All claims sourced below each frame.
